## Five axes

- **Correctness:** `prototypes/pi-stream-protocol.mjs:36–253` validates and copies the explicitly supported shared shapes without cross-version type casts. System/tool updates, signatures, Unicode, call/result associations, usage and terminal metadata survive. Unknown fields/modalities and lossy JSON fail, rather than disappearing. `:296–403` enforces action/case/epoch/route/sequence, serial block state, delta/end consistency, matching terminal content and one actual terminal. Supported error/aborted reasons remain failures, not successful summaries. Tests cover stop/length/toolUse, redacted/non-redacted thinking, tool argument deltas, malformed/oversized/truncated streams, wrong identities, late/duplicate terminals and poisoned receivers. The actual installed runtime round trip still receives the exact 1.3.0-normalized fixture contexts. This is not a native tool execution/SQLite proof.
- **Readability:** a single private protocol module owns shape, framing and per-request state. The existing parent owns process lifetime; the existing child owns synthetic SDK construction. No configurable provider abstraction or new dependency. The sizeable table-driven adversarial test file is deliberate coverage for one boundary, not another implementation or production framework.
- **Architecture:** `prototypes/pi-stream.mjs:48–121` sends only two fixed synthetic requests; `prototypes/pi-stream-child.mjs:154–180` validates exact fixture equality and performs one `streamSimple` per request. The second request is explicitly parent-driven, with a fixture tool result. No AgentSession, RPC prompt, helper tool executor, autonomous retry/compaction, durable transcript or production import is introduced. A model terminal is necessary but insufficient: the parent also requires both expected messages, clean EOF, exit 0 and empty stderr. Preparing request/receiver state precedes child startup.
- **Security:** fixed physical route and generation allowlist reject route/header/environment/API-key fallback requests. Both sides validate pipe data and retain no raw diagnostic/output capture. The isolated allowlisted child environment, selected-source verification and synthetic stores are unchanged; no default user auth store is opened. Fixed errors cross the boundary. Partial events/tool calls never authorize execution. `prototypes/pi-stream.mjs:79–129` kills/reaps on cancellation, timeout or protocol failure before deleting only its generated home. Synthetic tests exercise actual child rejection and PID reaping; trusted SDK/helper code still has host-user permissions. No claim of entitlement, live auth safety or OS egress confinement.
- **Performance:** UTF-8/LF records are bounded to 65,536 bytes including LF; pipe decoders cap total bytes (1 MiB) and records (1,024), with depth/message/block/delta limits. Child writes honor backpressure. No unbounded transcript/cache/history, shell, remote query or N+1 operation is added. No throughput optimization or benchmark gain is claimed.
