# Offline controller/native stream composition review

## Context and verdict

Starting from clean `8bfd4aa`, implement the next bounded [offline compatibility slice](../../pi-runtime-compatibility.md#offline-controllernative-composition), then stop. Apply `/skill:review` across correctness, readability, architecture, security and performance. This is a **five-axis author review**, not an independent-agent or cross-model audit.

**Verdict:** retain the bounded offline composition/evidence save point. **Important integration blocker remains:** native cancellation can acknowledge an action before helper cleanup completes. Do not approve full lifecycle parity, production adapter selection, real credentials/inference or M4 acceptance. No production source is changed to hide this limitation.

## Five axes

- **Correctness:** `test/pi-native-stream.test.mjs:79–117` checks actual native probe execution, exact second-request call/result identity, SQLite action-result persistence and no activity on reopen. `:120–214` checks Pause/Continue, preserved accounting and pre-dispatch expiry. `:217–306` exercises direct adapter abort/callback-failure cleanup and active native deadline denial. `:308–412` kills real controller subprocesses at model, persisted pause, uncertain tool and post-action-result/catalogue-receipt boundaries, then reopens real stores twice. No model text is treated as proof of a native effect. The child emits proper text deltas before text-end; its first attempt was correctly rejected by the existing protocol rather than relaxing validation.
- **Readability:** one single-action transport and one synthetic SDK child, plus a test-only provider alias/crash fixture. Reuse the existing framing/receiver/source checks and faux-only native guard. No production provider framework, new configuration surface or persistence abstraction.
- **Architecture:** `test/helpers/pi-native.mjs:21–46` reads only the already-admitted catalogue action and maps the synthetic provider alias explicitly. The existing controller owns action IDs/epochs, permission, budgets and recovery; native SQLite owns the sole transcript/tools. The helper never executes tools, prompts an AgentSession, retries, compacts or initiates another request. The probe is a synthetic trusted native operation, not container validation or genuine inference. The unresolved disposal boundary above prevents claiming full parity.
- **Security:** request/event validation remains bounded and fail-closed. `prototypes/pi-native-stream.mjs:17–99` checks abort/time before preparation/dispatch and at received chunks/closure, rejects diagnostics and waits for child closure before its own generated-home deletion. Callback errors and cleanup failures use fixed errors. `prototypes/pi-native-child.mjs:12–63` checks the environment/source identities and injects synthetic storage/configuration before runtime construction; no existing Pi files, ambient keys or default auth/model storage are used. The existing selected-source manifest is not a full transitive-install audit; trusted host SDK code/fetch sentinel is not an OS sandbox. No real auth change, service integration, worker policy or credential loading.
- **Performance:** one request/helper per admitted native model action, capped at ten seconds, with existing 65,536-byte lines, 1 MiB/1,024-frame decoding and structural bounds. Partial events stream without a raw transcript cache; terminal success waits for normal exit. Tests retain only bounded synthetic contexts in memory, close their read-only SQLite handles promptly and remove their temporary stores. Synchronous source/filesystem/test-callback work is trusted, not hard-real-time interruptible.
